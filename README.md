# Web/app học tập — KHTN 7, Bài 38

**Bài 38: TH: Quan sát, mô tả sự sinh trưởng và phát triển ở một số sinh vật**
Môn Khoa học tự nhiên 7 — Chương trình GDPT 2018, sách Kết nối tri thức với cuộc sống.

Trường TH và THCS Phước Hưng, xã Nhơn Hội, tỉnh An Giang.

## Nội dung

Web/app học tập 6 phần: Khởi động, Khám phá, Mô phỏng, Sơ đồ tư duy, Luyện tập (10 câu trắc nghiệm tự chấm), Vận dụng.

Mô phỏng gồm (bám đúng thí nghiệm thực hành trong PDF):
1. Hạt đậu sinh trưởng qua 7 ngày — kéo thanh thời gian, cây lớn dần trong chai nhựa, hiện chiều cao (≈ 0 → 15 cm) và số lá.
2. Vòng đời của bướm qua 4 giai đoạn: Trứng → Ấu trùng (sâu) → Nhộng → Trưởng thành (biến thái hoàn toàn).
3. Vòng đời của gà qua 4 giai đoạn: Trứng → Gà mới nở → Gà con → Trưởng thành (không biến thái, trứng ấp nở sau khoảng 21 ngày).

Kèm Bảng 38.1 (ghi chép sự sinh trưởng của cây, có ô nhập số liệu) và Bảng 38.2 (vòng đời của một loài động vật) theo mẫu SGK.

## Cách dùng

- Mở file `index.html` bằng trình duyệt bất kì (không cần máy chủ).
- Học sinh đăng nhập bằng Họ tên + Lớp, học 6 phần, làm 10 câu trắc nghiệm rồi nộp bài.
- Điểm tự động lưu về Google Sheets của giáo viên (qua Apps Script Web App, chạy bằng tài khoản giáo viên).

## File trong repo

- `index.html` — web/app hoàn chỉnh, tự chứa (hình ảnh nhúng base64).
- `Web_Hoc_Tap_KHTN7_Bai38.md` — bản sao toàn bộ mã nguồn kèm khóa đáp án (CABAABACDA).
- `Code.gs` — Apps Script Web App nhận điểm về Google Sheets (tab KetQua).
- `assets-flow/` — 3 ảnh nền (Google Flow) + logo giáo viên.
